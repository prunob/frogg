# Site de Frogg (GitHub Pages)

Pages publiques de Frogg, servies sur https://prunob.github.io/frogg/ (dépôt public `prunob/frogg`, branche `main`,
racine), sur le modèle d'Octo et de Palier. Publié le 10/11/2026 avec l'accord de Bruno.

- `index.html`, `support.html`, `privacy.html` : anglais (langue source de l'app).
- `fr/index.html`, `fr/assistance.html`, `fr/confidentialite.html` : français (espaces insécables appliquées).
- `style.css` : commun, clair et sombre. `images/` : icône, mascotte, 3 visuels de la fiche par langue (978 px).
- Pas d'`app-ads.txt` : Frogg n'a pas de pub.

URL à mettre dans App Store Connect :
- Assistance (page de la version) : https://prunob.github.io/frogg/support.html
  (français : https://prunob.github.io/frogg/fr/assistance.html)
- Confidentialité (Confidentialité de l'app) : https://prunob.github.io/frogg/privacy.html
  (français : https://prunob.github.io/frogg/fr/confidentialite.html)
- Marketing (facultatif) : https://prunob.github.io/frogg/ (français : https://prunob.github.io/frogg/fr/)

Les autres langues de la fiche pointent vers les pages anglaises.
Le bouton « Bientôt sur l'App Store » est à remplacer par le lien de l'app quand elle sera publiée.

Mise à jour : remplacer les fichiers dans le dépôt GitHub (interface web, « Add file › Upload files »).
